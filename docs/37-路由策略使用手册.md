# 路由总览与策略使用手册

路由总览、场景方案、会话保持、意图选模、敏感内容检测与拦截已发布，支持 Claude CLI、Claude 桌面端及 Codex 分类。先添加并启用对应分类的 Key，再配置策略；这些可选策略默认关闭。此处说明实际操作，不代表所有客户端版本、上游账号及签名历史组合均已验收。

## 查看路由总览

打开「路由总览」，分别查看三类客户端的代理监听、配置主 Key、模型选项、配置接入检查和最近线路尝试。配置指向正确不等于正在运行的客户端已经重新加载配置；「已建流」仅表示流已建立，不表示完整回答成功。没有请求记录时会显示空状态，不用配置值冒充实际结果。

## 保存和切换场景

1. 打开「路由策略 → 场景方案」，点击「从当前配置新建」。
2. 填名称，勾选要包含的客户端分类，选择主 Key、模型及 Codex 档位兜底。未包含的分类不变；「不改变主 Key」保留应用时的主 Key。
3. 点击保存。保存只记录方案，不立即切换。
4. 点击「预览应用」，核对每个分类的当前值、目标值及客户端文件变更，再确认应用。
5. 检查逐分类同步结果。本地选项已保存但客户端同步失败时，排除文件占用或权限问题后重试同步。

场景不复制密钥、不启停代理、不更改登录态或旧会话，也不会关闭隐私策略。只同步运行中且仍由 SynaRoute 接管的客户端模型配置；写入前保留备份，不覆盖接入前快照。预览有效期十分钟，配置、文件或代理状态改变后须重新预览。已有会话可能保留旧模型；模型目录变化后重启客户端。

## 设置会话保持

在「会话保持」中选择分类和模式，然后点击「保存此分类策略」并确认：

- **关闭**：沿用普通选路。
- **本轮保持**：同轮后续请求尽量沿用成功的 Key。
- **整个会话保持**：同模型的后续回合尽量保留线路。

保持服从模型能力、熔断、配额、余额和预算，不强行使用不可用 Key。故障转移成功后可保持新线路，流内失败使对应绑定失效。必须有可靠会话身份；无法识别时不把多个请求合入默认会话。需要重新选路可点击「清空此分类保持记录」。不保证跨账号缓存命中或签名历史兼容。

## 配置意图选模

1. 在「意图选模」选分类，添加自动路由组并填写名称。
2. 选择默认模型、判断 Key 和该 Key 的真实判断模型。
3. 添加意图说明与目标模型，按所需顺序调整规则，启用并保存。
4. 在客户端模型菜单或场景中选择对应 Auto 入口；仅创建规则不会接管普通真实模型请求。目录变化后重启需要重新加载目录的客户端。

可识别的新回合最多判断一次，工具续传沿用选择。判断最多等待四秒且受总请求预算约束；失败、无匹配或无法识别身份时通常回默认模型。最新用户文本和规则说明会发给指定判断模型，可能产生费用，按判断 Key／真实模型记账，不额外发送完整历史和工具输出。带签名或服务端引用的历史若无法确认原模型，会明确拒绝并要求选择原有真实模型，而不是猜测切换。

## 检查敏感内容

在「敏感内容」选分类及模式，勾选凭据、邮箱或大陆手机号规则，再保存：

- **关闭**：不做该项检查。
- **仅提醒**：记录命中类型和数量，原文仍发送。
- **拦截**：命中、扫描超限或规则加载失败时拒绝请求，在判断模型和业务上游调用之前执行。

自定义词每行一个，最多100个，每个至少3字符、不超过256字节。勾「替换已保存的敏感词」才替换；保存空替换会清空，未勾选则保留旧词库。词库加密保存，只回显数量。锁库时不可读取或编辑，拦截模式不因此放行。

「本地试扫」不调用模型、不保存试扫正文；使用当前检测开关和已保存词库，不使用未保存词草稿。结果显示命中数量和遮盖文本。未命中不是安全证明：规则有误报和漏报，不识别图片、二进制附件及加密推理，不覆盖独立大脑会诊、原生受控客户端及绕过代理的调用。提醒模式不会关闭原始正文日志，排障后应关闭不再需要的正文记录。

## 常见问题

- **保存提示配置已变化**：先放弃旧草稿、刷新，再基于新状态编辑，避免覆盖其他入口的修改。
- **Auto 入口不可用**：确认组已启用、判断 Key 有效、真实模型仍可用；关闭或删除的入口不会静默透传。
- **客户端待同步**：本地策略不因同步失败撤销。核对分类代理是否运行、客户端是否仍受接管及文件权限，再重试。
- **读取失败或旧快照**：不代表策略关闭；刷新并核对后端状态。
