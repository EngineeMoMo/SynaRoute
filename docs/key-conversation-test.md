# 单 Key 会话测试

在分类页每张 Key 卡片的操作区点击对话气泡图标，打开「单 Key 会话测试」。选择或输入模型名（可使用该 Key 的映射名），输入消息并发送。后续消息携带当前窗口里的已成功对话，适合检查模型是否能够连续理解上下文。

- 固定使用所选 Key，不启动代理、不切主 Key、不故障转移，也不调用大脑聚合。禁用的 Key 仍可手动测试；花费预算仍生效，主口令库必须先解锁。
- 支持 Anthropic Messages、OpenAI Chat Completions 和 OpenAI Responses；后端读取密钥，不将凭证传给前端。Responses 与 Chat 请求显式关闭服务端 `store` 选项，但这不代表第三方供应商绝不会保留请求。
- 显示实际模型、完成耗时、上游返回的 token 用量及输出截断提示。未返回用量时显示「上游未返回用量」，不会伪造为零；已收到的用量归入所选 Key 的用量账本，不改变健康评分。
- Enter 发送，Shift+Enter 换行，支持中文输入法合成状态。更换模型会清空会话；更换 Key 接口或协议后必须重新打开测试窗口。
- 「停止请求」、关闭窗口或离开分类会取消本次请求；起始确认尚未返回时发出的停止也不会丢失。可以在活跃请求列表按请求 ID 查看或停止测试。取消不触发另一个 Key 或后台重试。
- 每次回复最多请求 2048 输出 token，超时最多 120 秒，同时最多 4 个测试；每条消息不超过 32 KiB，总历史不超过 128 KiB，最多保留 31 轮历史。超限会明确要求缩短或清空，不会悄悄丢弃上下文。
- 正文只保留在当前窗口，不写本机对话文件或详细请求日志；本机仅记录结果、耗时和用量。回复按纯文本显示，不执行模型给出的 HTML。
- **这是收费上游的真实请求，可能消耗额度。** 关闭连接不保证供应商立即停止生成或停止计费；尚未收到的用量无法补算。纯浏览器预览不会假装测试成功，必须在桌面应用中发送。

本地模拟上游的协议、凭证隔离、错误处理与取消回归见 `src-tauri/src/proxy/key_chat_tests.rs`；原生窗口验收统一记录在 `docs/14-交接与待办清单.md` §21.2 的 C-62，不以自动测试替代真实供应商验收。
