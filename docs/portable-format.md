# 配置备份与凭证迁移

## 导出格式 v3

- 包含 Key、聚合配置、厂商、可移植设置，以及自动路由组、会话亲和、场景、隐私策略和判断服务配置。
- 不含密钥导出不会包含余额面板 Access Token 明文；凭证引用本身不包含凭证内容。
- 含密钥导出使用用户口令加密 API Key、余额覆盖凭证、面板 Access Token、判断服务密钥和隐私敏感词。仅导出配置实际引用的条目，不导出 LAN 访问令牌或无关内部密钥。
- 端口、MCP 注册、代理运行状态、自启动、日志目录和 LAN 暴露状态仍按本机处理，不随备份启用或覆盖。

## 兼容与导入

- 继续校验并读取 v1、v2 备份的原始载荷摘要；v2、v3 使用递归排序后的 JSON 摘要。
- 替换导入恢复备份中的路由和判断服务配置。旧格式未包含这两项时重置为空，避免引用已删除的 Key。
- 合并导入保留本机额外的路由组、场景和分类，按 ID 覆盖同名实体；旧格式缺失的路由和判断服务配置保持本机值。
- 不含密钥的备份在新机器上需要重新配置对应凭证。隐私敏感词仍保留引用，缺失时由隐私检查报错，不能视为已恢复词库。

## 余额面板凭证

- 新保存的 Access Token 写入加密密钥库；普通配置仅保存 `accessTokenRef`。
- 升级时先写入密钥库，成功后才移除配置中的旧明文。若主口令库锁定，迁移延迟至解锁；解锁前的无密钥导出仍会移除明文。
- 已有旧版备份和日志不会被自动改写。旧备份可能含 Token 明文；请重新导出并妥善保管旧文件，若曾对外分享则应轮换相关凭证。
- 编辑器不回显已保存的 Token。不输入时保留；输入替换值后保存会换用新凭证，点击「移除」并保存可清除引用。
- 被替换或移除且不再被其他 Key 引用的面板凭证，可通过设置页的孤儿密钥清理删除。
- 余额配置或凭证变更立即失效后端缓存；变更前发出的查询不能回写旧结果或自动探测地址。

## 旧备份的检测与脱敏

- 在设置页选择「导入配置」并选中旧备份，预览会单独报告明文余额面板 Token 的数量，不显示 Token 内容。没有加密密钥段不代表旧文件没有敏感凭证。
- 检测到明文时，点击「另存已移除明文 Token 的副本」。无需执行导入、提供备份口令或解锁密钥库；此操作不改变本机配置。
- 先校验原备份的格式与摘要，再仅移除 `payload.keys[].balanceQuery.accessToken` 字段，并重新计算摘要。保留其他配置、未知扩展字段、凭证引用和原有加密密钥段；这不等于完整的「不含密钥」导出。
- 支持 v1、v2、v3；v1 副本转换为 v2 的规范化摘要，v2、v3 保持原格式版本。脱敏后的相关余额查询可能需要重新配置凭证。
- 也可选择旧的 `config.pre-import-*.json` 本机回滚文件，检测并移除 `keys[].balanceQuery.accessToken`。这类文件没有导出摘要，副本保持原格式，不伪装成可移植备份；界面禁止直接导入。手工回滚需退出应用并配合对应密钥库还原，文件仍可能包含其他敏感配置，不应直接分享。
- 必须另存为新文件，不能覆盖原文件或已有文件。副本先写入同目录临时文件并同步，完整写入后才以不覆盖方式发布；写入失败会清理临时文件，不留下半写的目标备份。原文件、其他副本及历史日志不会被自动清理，仍须按敏感文件处理；若曾对外分享，应撤销或轮换相关 Token，仅生成脱敏副本不能使已泄露的凭证失效。

## 自动回滚备份与文件大小

- 替换导入和分享模板导入共用安全备份入口。磁盘旧配置含明文余额面板 Token 时，先将 Token 加密保存到本机密钥库，再在回滚副本中改为凭证引用；不会直接删除唯一可恢复的凭证，也不会改写原文件。若密钥库锁定、读取异常或凭证写入失败，则拒绝生成备份并停止导入。
- 原配置只在确实不存在时使用内存快照；读取失败、文件过大或格式损坏不会被当作「空配置」。回滚文件使用时间戳加随机标识，并以不覆盖方式保存，同一秒的多次导入也不会覆盖旧备份。恢复回滚副本仍依赖对应密钥库。
- 密钥库重写前的备份（导入清理、主口令变更、损坏恢复等）同样使用随机文件名和完整写入后不覆盖发布，避免同一秒的操作覆盖较早的可恢复密文。仅源文件确实不存在时跳过备份；备份失败不会继续不可逆的清理或重写。
- 替换导入会在修改配置或写入密钥前备份整个密钥库，包括「没有删除 Key、只是覆盖同 ID 密钥」的情况；备份失败则停止导入。成功报告同时给出配置与密钥库备份路径，回滚时需要配套恢复。
- 导入预览、正式导入、旧备份脱敏、自动回滚备份和密钥库备份读取统一限制为 **32 MiB**。同时检查文件大小与实际读取字节，最多读取上限加 1 字节，防止读取期间文件增长绕过限制。超限时不导入、不输出副本；导出文件、新回滚副本及脱敏副本也不得超过此限制，避免生成无法重新导入的备份。
- 配置备份预览、正式导入和旧备份脱敏的文件 I/O 与校验工作在阻塞任务池执行，不占用异步工作线程。

## 上游响应限制

- 非流式成功响应最多 64 MiB，错误响应和余额响应最多 1 MiB，同时检查声明长度和实际累计字节。
- 超限作为明确的上游失败处理；正常 SSE 流不受总字节限制，保留取消和超时机制。
