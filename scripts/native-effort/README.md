# 原生自动思考（预览）

入口：SynaRoute → 大脑聚合 → 原生自动思考。

1. 客户端自动跟随当前分类：Codex 分类使用 Codex，两个 Claude 分类使用 Claude Code（Claude 桌面分类也需要本机安装 Claude Code）。自动查找 PATH、常见 npm 安装位置和 Codex 桌面内置 CLI；工作目录复用当前分类配置或已开启的自动跟随项目。检测成功即可启动；未找到时在“手动调整”中补充路径或选择项目文件夹。“重新检测”可更新结果。Windows 使用原生 `.exe`，不会运行 `.ps1` / `.cmd` 包装器。
2. 启动独立会话，从客户端返回的目录选择模型与手动档位。首次提交后固定模型；可在后续提问前修改手动档位。
3. 可选：在上方“动态思考”保存 Jev、Laya 或兼容 Chat 判断服务，打开本面板“自动选择原生档位”。此开关独立于会诊模式；没有服务也可手动使用，服务异常时沿用手动档位。
4. 提交任务。客户端要求工具授权时，检查请求后选择允许本次或拒绝。关闭面板所在页面会关闭该会话；主动停止也会关闭会话，不支持恢复。

使用已有 CLI 登录、环境与配置，原生客户端照常决定实际计费、工具权限和沙箱行为。SynaRoute 不修改全局模型档位配置，不附着到已打开的官方窗口。该预览是独立受控会话界面，不是官方窗口扩展。不要把“原生控制已确认”理解为远端厂商必然执行了该参数；模型目录也不代表账号有调用权限。

每个用户回合开始前选择原生档位：Codex 使用 `model/list`、`thread/start`、`turn/start.effort`；Claude 使用初始化模型目录及 `apply_flag_settings.settings.effortLevel`，等待控制响应后才发送用户输入。判断直接从原生目录选值，包括运行时实际提供的 `xhigh/max/ultra` 等，不映射到固定三档。模型保持固定。

自动判断只发送本次问题文本，不发送项目文件或完整对话；缺乏上下文的跟进问题可能回退。判断预算四秒，异常、低置信度、未知值、目录外档位均回退。原生控制失败会关闭会话并报错，不会用未确认档位继续发送任务。不会自动重试付费轮次。

当前边界：没有生成过程中的检查点调档，没有接管现有官方窗口，没有缓存命中或省费承诺；尚未验证真实付费判断服务的分类质量及所有客户端版本。只支持已识别的命令执行／文件修改工具审批和 Claude `can_use_tool`；其他需要回答的控制请求明确拒绝。进程关闭不撤销已完成的工具操作。

## 可重复验收

```powershell
node scripts/native-effort/probe.mjs --codex <codex.exe绝对路径> --claude <claude.exe绝对路径> --adapter-tests
```

需要 Node、Rust 工具链和已安装的客户端。可加 `--cargo <cargo绝对路径>`。脚本创建独立临时工作目录和客户端 home，清除继承的模型服务凭据，以假 Key 连接 loopback 模拟上游；不调用付费模型、不执行模型工具、不替换已安装客户端。报告写入脚本打印的临时目录。

测试既覆盖原始协议，也调用生产 Rust 适配器：同一模型 low→high、完整回复、无判断服务回退、手动模式、拒绝换模型、过期审批、判断中取消与迟到结果丢弃及进程关闭。默认 Cargo 回归忽略此测试，由上述脚本单独运行。

2026-10-08 本机验证：Codex `0.162.0-alpha.2`、Claude Code `2.1.232`。两个原生客户端及生产适配器均在模拟上游完成 low/high 两轮；这证明协议和请求字段贯通，不证明真实厂商推理质量。真实账号、权限交互、更新兼容、缓存与资源占用验收统一记录在 `docs/14` C-51。
