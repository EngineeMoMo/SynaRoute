# 隐私政策

本政策说明 SynaRoute 软件与本网站分别处理哪些信息。

## 一、SynaRoute 软件

### 不收集任何个人信息

SynaRoute 是一款完全在你本机运行的桌面软件。它**没有账号体系，不需要注册或登录，不做配置同步，也不收集任何使用数据或行为统计**。我们没有服务器接收你的任何数据。

### 数据存放在哪里

配置 config.json 与密钥库 secrets.enc 位于用户应用数据目录的 SynaRoute 文件夹：Windows 通常为 %APPDATA%\SynaRoute，macOS 为 ~/Library/Application Support/SynaRoute，Linux 为 $XDG_DATA_HOME/SynaRoute（未设置时为 ~/.local/share/SynaRoute）。日志可能位于其他目录，请在设置中确认实际路径。

如设置了 SYNAROUTE_DATA_DIR，配置与密钥库改用该目录；请以实际设置为准。密钥本地保存，不上传 SynaRoute 云端；上游请求会使用密钥向你配置的端点鉴权。

- `config.json` —— 你的 Key 列表、模型映射、各项设置；
- `secrets.enc` —— 加密后的 API 密钥。

默认日志仅记录元信息；开启「记录调用模型日志」后会包含对话正文与系统提示词，仅建议临时排障使用。Windows/Linux 优先写入可执行文件同级 logs，不可写时回退应用数据目录的 SynaRoute/logs；macOS 默认 ~/Library/Logs/SynaRoute。支持自定义日志目录，以设置页显示的路径为准。

### 密钥如何保护

Windows 默认使用 DPAPI，将密文绑定当前用户账户；macOS 使用系统钥匙串保管随机加密密钥。两者均可切换为主口令模式。Linux 必须先设置主口令，不提供固定密钥回退。主口令模式使用 Argon2id + AES-256-GCM，每次启动需解锁，忘记口令无法恢复密钥。

旧版 Linux 固定密钥库不会自动迁移或覆盖。升级前请备份；如遇旧库拒绝读取，退出应用后将 secrets.enc 移出数据目录，重启、设置主口令，再录入上游密钥。建议轮换旧密钥；确认新库可用后妥善清理旧备份。

需要说明的是，加密防的是文件被复制走，**不防已经以你的账户身份运行的程序**。

### 软件会往外发什么请求

只有两类：

1. 你自己配置的上游厂商请求——即转发的 AI 调用，发往你在 Key 里填写的地址；
2. 检查新版本时对项目发布页的请求。

除此之外没有任何外发请求。

### 关于日志

运行日志默认只记录元信息：时间、命中的是哪个 Key、请求的模型解析成了什么、上游返回的状态码、是否发生了故障转移。

设置里有一个「记录调用模型日志」开关，**默认关闭**。开启后日志会额外包含**完整的对话正文，包括系统提示词**。建议仅在排查问题时临时开启，查完关掉。所有日志只写在本地，不会外发。

### 如何删除你的数据

卸载前先停止代理并恢复客户端配置，在设置中记下应用数据目录与日志目录，然后退出应用。删除 SynaRoute 应用数据文件夹（含配置、密钥库及备份），另行删除实际日志目录及曾使用的自定义日志目录。自行导出的配置、诊断报告及客户端配置备份也需按保存位置单独清理；只删除应用数据目录并不保证清理完整。

## 二、本网站

本网站是一个静态站点，托管在 GitHub Pages 上。

- 网站本身**不设置任何跟踪 Cookie**，不加载第三方广告或统计脚本；
- 你的主题与语言选择存放在浏览器本地存储里，仅用于下次访问时保持一致，不会发送到任何地方；
- 下载页会向 GitHub 的公开接口请求最新版本信息，用于显示版本号和下载链接；
- 作为托管方，GitHub 可能按其自身政策记录访问日志（如 IP 地址）。这部分不受我们控制，详见 GitHub 的隐私声明。

## 三、第三方服务

你在 SynaRoute 里配置的每一个上游厂商，都是**独立的第三方**。你的请求内容会发送给它们，如何处理由它们各自的条款决定。请自行阅读你所使用厂商的隐私政策。
