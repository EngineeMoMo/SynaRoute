# 隐私政策

本政策说明 SynaRoute 软件与本网站分别处理哪些信息。

## 一、SynaRoute 软件

### 不收集任何个人信息

SynaRoute 是一款完全在你本机运行的桌面软件。它**没有账号体系，不需要注册或登录，不做配置同步，也不收集任何使用数据或行为统计**。我们没有服务器接收你的任何数据。

### 数据存放在哪里

所有配置与密钥都存放在你电脑上当前用户的应用数据目录下的 `SynaRoute` 文件夹中：

- `config.json` —— 你的 Key 列表、模型映射、各项设置；
- `secrets.enc` —— 加密后的 API 密钥。

日志文件默认写在软件目录下的 `logs` 文件夹，也可以在设置里改到别处。

### 密钥如何保护

默认使用 Windows 数据保护接口（DPAPI）加密后落盘，密文与你当前的 Windows 账户绑定，复制到别的机器或别的账户下无法解出。

你也可以在设置里开启主口令增强模式，改用你设定的口令通过 Argon2id 派生密钥、配合 AES-GCM 加密。开启后每次启动需要先解锁。

需要说明的是，加密防的是文件被复制走，**不防已经以你的账户身份运行的程序**。

### 软件会往外发什么请求

只有两类：

1. 你自己配置的上游厂商请求——即转发的 AI 调用，发往你在 Key 里填写的地址；
2. 检查新版本时对项目发布页的请求。

除此之外没有任何外发请求。

### 关于日志

运行日志默认只记录元信息：时间、命中的是哪个 Key、请求的模型解析成了什么、上游返回的状态码、是否发生了故障转移。

设置里有一个「记录调用模型日志」开关，**默认关闭**。开启后日志会额外包含**完整的对话正文，包括系统提示词**。建议仅在排查问题时临时开启，查完关掉。所有日志只写在本地，不会外发。

### 如何删除你的数据

卸载软件后，删除应用数据目录下的 `SynaRoute` 文件夹即可清除全部配置与密钥。如果你改过日志目录，另行删除该目录。软件不会在其他位置留存数据。

## 二、本网站

本网站是一个静态站点，托管在 GitHub Pages 上。

- 网站本身**不设置任何跟踪 Cookie**，不加载第三方广告或统计脚本；
- 你的主题与语言选择存放在浏览器本地存储里，仅用于下次访问时保持一致，不会发送到任何地方；
- 下载页会向 GitHub 的公开接口请求最新版本信息，用于显示版本号和下载链接；
- 作为托管方，GitHub 可能按其自身政策记录访问日志（如 IP 地址）。这部分不受我们控制，详见 GitHub 的隐私声明。

## 三、第三方服务

你在 SynaRoute 里配置的每一个上游厂商，都是**独立的第三方**。你的请求内容会发送给它们，如何处理由它们各自的条款决定。请自行阅读你所使用厂商的隐私政策。

## 四、变更

本政策如有变更，会更新本页内容。
